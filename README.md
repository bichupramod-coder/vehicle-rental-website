# Vehicle Rental Website Starter

Responsive static website starter with Home, Vehicles, Vehicle Details, About and Contact pages.

## Run locally
Extract the ZIP, open this folder in VS Code, then open `index.html` in a browser. You can also use the VS Code Live Server extension.

## Mandatory customization before publishing
1. Edit `vehicles-data.js`: replace demo vehicles, prices, photos, specifications and every sample rental condition with verified business details.
2. Change `RENTAL_WHATSAPP` to the business WhatsApp number in international format, digits only (India: 91 + 10-digit number).
3. Replace demo brand name, contact details, service area and About text in the HTML files.
4. Use photographs of the actual fleet and ensure you have permission to use them.

## Included
- Responsive layout and mobile navigation
- Vehicle cards, search and category filter
- Vehicle details and sample rental terms
- WhatsApp enquiry links and form (opens WhatsApp; does not save enquiries)

## Not included
No admin dashboard, database, live availability, booking calendar or online payments. Sample prices/conditions are placeholders and must not be presented as actual offers.

## Deploy to Vercel
Upload this folder to a GitHub repository, import it in Vercel, choose the `Other` framework preset, leave the build command empty, and deploy. Add your custom domain in Vercel project settings and use the DNS records Vercel provides.
